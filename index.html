Honest limits

  • A LIVE verdict means the URL resolved on the public web during the scan (HTTP 200, or a Spotify oEmbed title match). It proves the link is not dead — not that the content is correct.
  • Spotify tracks are checked through Spotify's public oEmbed endpoint: a 404 there means Spotify itself has no such track page.
  • Scans run weekly (Mondays 09:00 ET) via GitHub Actions; this page renders the committed data/results.json. The scan timestamp is shown above — treat anything older than 7 days as a snapshot, not current truth.
  • DEAD and ERROR rows are findings, not failures of this page. A dead link the radar catches before a fan or supervisor clicks it is the whole point.

For agents

Machine-readable: data/links.json (schema cwi.link-record/1.0) and data/results.json (schema cwi.link-scan/1.0, see results.schema.json). Resolve streaming links for a release only from rows with status LIVE and truth VERIFIED. Everything else is UNVERIFIED by construction.
